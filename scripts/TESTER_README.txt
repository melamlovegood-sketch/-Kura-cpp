Kura Windows 测试版使用说明

适用系统：Windows 10 / Windows 11，64 位。

1. 双击 Kura 安装程序，按提示完成安装，不需要安装 Qt 或编程环境。
2. 从桌面或开始菜单打开 Kura，首次使用可跟随新手引导设置预算。
   全新 Windows 用户首次打开是空账本，不会包含项目方记录。在曾使用 Kura 的同一 Windows 账户重新安装，会继续读取此账户原有账本和设置；这是保留数据的正常行为，卸载也不会清空它们。
3. 想先体验虚构数据，可从开始菜单打开“Kura Demo”；退出后演示数据删除。
4. 本地记账、清单、预算与复盘可直接使用。AI 功能需在“设置 → AI 服务”配置自己的 API Key，页面内有申请教程。本常规测试包不提供共享 Key。
5. 日常数据保存在本机，升级或卸载程序不会删除账本。建议在“设置 → 数据管理”定期备份。
6. 遇到问题可通过“设置 → 问题反馈”联系 meilintan@bupt.edu.cn，请附软件版本、操作步骤及必要截图。

卸载：Windows 设置 → 应用 → 已安装的应用 → Kura → 卸载。
用户数据目录：%LOCALAPPDATA%\Kura\KuraCpp。

程序使用 Qt 6.10.1 动态库，许可证及第三方声明位于安装目录 licenses。
Qt 对应源码：https://download.qt.io/archive/qt/6.10/6.10.1/single/
