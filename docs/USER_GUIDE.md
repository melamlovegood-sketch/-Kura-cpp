# Kura C++ 使用说明

适用版本：0.12.6。程序是本地 Windows 桌面应用，业务数据保存在本机，不需要账户登录。基础操作可离线；AI 解析和分析需要网络与个人 API Key。复盘首页展示动物消费人格、短故事、下月小任务、三个数字与值得／后悔列表，购买后复盘和统计从底部次级入口打开；本地总结在故事的“更多”菜单中。新功能见 IMPORT_MONTHLY_REVIEW.md，其他流程见 DECISION_FLOW.md、WORKFLOW_PHASE3.md。

## 启动

先解压整个程序目录，再运行 `KuraCpp.exe`。DLL 和插件文件夹必须与程序一起保留。首次启动创建本地数据库，以后自动恢复原数据。

双击 `Demo.cmd` 可启动演示模式；也可以运行 `KuraCpp.exe --demo`。标题和底部标识会说明正在使用演示数据。每次使用新的临时数据库，正常退出后自动删除，不修改正式消费记录。演示中另存到其他位置的 CSV 或备份由使用者保留。

## 页面与外观

启动打开“主页”，显示本月预算和待决定愿望。底部导航依次为“主页、账单、清单、执行、复盘”，也可以使用 Alt+1 至 Alt+5。右上角齿轮进入设置，切换暖色／冷色／深色；外观自动保存。“数据管理”在设置内。

主页“我现在想买……”打开统一输入面板。设置中保存支持图片的 AI 模型和 Key 后，可用文字或截图生成初稿，核对后选择忍住、加入清单、购买或蹲价格。没有配置 AI 也可手动填写。

## 月度复盘

复盘页分为月度、购买后和年度统计三页。月度页可切月查看事实、上月对比、个人值得／后悔标记、画像和高光。没有 AI 也可保存本地总结；AI 仅点击时生成故事，数据变化后提示旧故事过期。月度标记不重复改变品牌权重。

## 决策、品牌与购买后复盘

设置中维护购物原则和信任品牌。执行页填写商品，查看本地简报，选择快速决策或研究模式；开始后可保存研究记录，重启会恢复会话。AI 补充分析和问答需要点击才请求。确认购买可选品牌，会同时保存消费和 7／30 天复盘任务。

复盘页上方显示购买后任务，未到期时不能提交。两题评价保存后，只对有效品牌反馈一次：值得 +1、后悔 -1、一般不变。下方保留原年度与分类统计。普通账单新增不自动生成购买复盘。

## 蹲价格

清单中切换“蹲价”，右上角添加商品，商品行显示最近价格和目标价。点击商品行展开后，可追加手动价格、查看趋势、设置目标价和商品链接；再次点击收起。“···”菜单可查看已结束追踪和刷新。首页提醒依据已保存的价格，点击“知道了”保留已读状态。这里不自动获取商城价格，价格记录也不会生成支出。

## 记账与预算

从底部“账单”进入。

账单首页直接输入一句消费描述或上传截图，点击“AI 解析”，核对名称、金额与分类后再保存。也可切到“手动”，填写名称、金额、分类和可选备注后保存。消费金额须大于零，最多两位小数；补记可改日期。

首页只展示最近三笔，点开侧边详情可修改或删除。“查看当月全部”进入完整列表，支持筛选、双击修改及新增时填写具体时间，点击“返回记账”回到首页；删除确认默认取消。

点击“图表”默认打开消费日历，点日期查看当天摘要；“折线趋势”可切换本月每日／近六个月。右上角“记一笔”返回录入区。

选好分类和日期后点击“筛选”，才会改变列表。“重置”显示全部记录。页面上的“显示范围”代表已经应用的条件；没有结果时会显示提示。

从右侧“调整预算”打开编辑窗口。月度预算按年月保存，分别填写基础生活和可支配额度后点击“保存预算”。标签显示数据库已保存的合计、全月已消费和剩余额度；输入框内尚未保存的数值不会改变额度。旧总预算尚未分配时有明确提示。首页显示两项实际使用及剩余；单项或总额超支均会提示。预算、当前月分类汇总和全局金额不受列表筛选影响。

工作台侧栏显示支出最高的三个分类。完整记录页保留六类汇总，合计等于本月支出，空分类保留零。

## 消费统计

从底部“复盘”进入。

按年份查看 12 个月趋势、全年金额、月均和最高支出月份。月均按全年金额除以 12 计算，包含空月份。悬停月份查看金额与笔数，双击图表或使用明细按钮可以跳转到对应月份的记账与预算。

下方切换“分类复盘”，选择顶部年份和复盘月份，可查看六类的金额、笔数、占比、上月金额以及变化。变化为所选月减去上月，跨年也按自然月比较；占比显示一位小数，舍入后的合计可能略有差异。列表筛选不会影响这些结果。

## 愿望清单

在“待购”页点击右上角“添加商品”，填写名称、预计价格、分类、优先级、冷静期天数和理由。优先级为高、中、低，默认中；冷静期默认 3 天，即 72 小时，可设置 1 至 30 天。默认只显示待购商品，已购买／已放弃历史在“···”菜单中切换。点击商品行展开资料和购买、修改、放弃等操作，再次点击收起。

截止前不能购买；到期后点击“购买并记账”，确认实际金额、日期时间和备注。只有保存成功才改变愿望状态并产生消费，预算和统计同时更新。可以随时放弃，放弃金额不算支出。

修改待决定的愿望会重新开始冷静期。已购买或已放弃的条目保留为历史。删除愿望不会删除已记录的消费。旧版愿望升级后优先级默认为中。

## 数据管理

从设置进入“导入历史账单”，选择微信／支付宝 CSV、XLSX 或 Kura CSV。先选择或拖入文件，再核对名称和分类，最后点击底部“导入 N 笔”一次保存。分类无需逐项另行确认；搜索和“待核对”可帮助集中修改，批量分类只修改当前列表中勾选的记录。疑似重复默认不选，失败整批回滚。默认保留全部历史。examples 有虚构样例，建议在演示模式试用。

完整备份保存十四张业务表，包括截图、许愿池、原则、品牌、会话、复盘、价格历史、导入索引和月度故事，API Key 不在备份中。恢复旧版备份时，该版本没有的新模块一并重置为空，恢复前的自动备份可用于撤回。

从右上角设置进入“数据管理”。

CSV 可导出全部已保存消费或已应用的筛选结果，包含完整备注。完整 SQLite 备份还包含预算和愿望，支持恢复。

恢复会整体替换三类数据。程序先检查文件，显示各类数量，确认后先保存现有数据的自动备份，再恢复。筛选和未保存的预算输入会重置。自动备份路径在成功提示中可复制，可再选此文件撤回恢复操作。

存在打开的编辑表单时，请先保存或取消。文件不兼容、数据库被占用或恢复中途失败时，保留原数据并显示原因。

## 数据位置与常见问题

正式数据通常位于 `%LOCALAPPDATA%\Kura\KuraCpp\kura.sqlite`，状态栏悬停可查看实际路径。自动备份在数据库所在目录的 `backups` 中。程序升级沿用原数据。

不能启动时，检查是否完整解压并保留 `platforms/qwindows.dll`、`sqldrivers/qsqlite.dll` 和所有 DLL。数据库失败时先查看页面提示，关闭其他占用数据的程序后重试。保存失败时表单保留输入，不要重复新增已经提示保存成功的记录。
