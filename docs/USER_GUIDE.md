# Kura C++ 使用说明

适用已验收基线：0.17.0，开发中功能以 [版本统一记录](VERSION_UNIFICATION.md) 为准。程序是本地 Windows 桌面应用，业务数据保存在本机，不需要账户登录。基础操作可离线；AI 解析和分析需要网络及个人配置，授权小组测试包也可使用 Kura AI 试用。复盘首页展示动物消费人格、短故事、下月小任务、三个数字与值得／后悔列表，消费评价使用“标记一笔”，分类与趋势在账单页查看；本地总结在故事的“更多”菜单中。专题入口见 [文档索引](README.md)。

## 启动

完整本地项目工作区统一使用上一级“启动最新版.cmd”或“体验最新版.cmd”。GitHub 源码下载不包含运行依赖与这两个本地入口；从源码开始见 [构建与发布](RELEASE.md)。下面的程序启动方式适用于已构建的完整运行包。

先解压整个程序目录，再运行 `KuraCpp.exe`。DLL 和插件文件夹必须与程序一起保留。首次启动创建本地数据库，以后自动恢复原数据。

双击 `Demo.cmd` 可启动演示模式；也可以运行 `KuraCpp.exe --demo`。标题和底部标识会说明正在使用演示数据。每次使用新的临时数据库，正常退出后自动删除，不修改正式消费记录。演示中另存到其他位置的 CSV 或备份由使用者保留。

## 页面与外观

启动打开“主页”，上方显示本月预算和许愿池，下方按需显示进行中的分析及最多两件已结束冷静期的商品。点击商品的“现在还想要吗？”会进入清单并展开对应条目，“查看全部”只显示待决定商品；没有待处理事项时对应区域收起。许愿池的忍住金额累计记录消费选择，不代表实际存款；“查看目标”直达商品资料，“更换目标”进入清单。底部导航依次为“主页、账单、清单、执行、复盘”，也可以使用 Alt+1 至 Alt+5。右上角齿轮进入设置，切换暖色／冷色／深色；外观自动保存。“数据管理”在设置内。

主页“我现在想买……”打开统一输入面板。设置中保存支持图片的 AI 模型和 Key 后，可用文字或截图生成初稿，核对后选择忍住、加入清单、购买或蹲价格。没有配置 AI 也可手动填写。

## 月度复盘

复盘页直接展示月度人格故事、支出／忍住次数／忍住金额及值得／后悔列表。可切换月份，点击“标记一笔”评价消费。没有 AI 也可保存本地总结；AI 仅点击时生成故事，数据变化后提示旧故事过期。月度标记仅记录这笔消费的评价。

## 决策与购物原则

执行页下方仅展示已结束冷静期的待决定商品。点击「去决策」直接带入商品信息并选择快速／研究模式；确认购买或放弃会处理原清单条目，「继续等等」则保留原条目和原冷静期，不重复添加。仍在冷静中的商品只在清单里等待。

把商品加入清单前，点选一次「现在有多需要？」：高优先（近期确实要用）、中优先（有明确用途，可以等等）、低优先（暂时想要，不着急）。新商品不预选，已有商品修改时保留原选择。清单默认高优先在前，同级新添加的在前；右上角菜单可改为按时间或手动排序。主页的冷静期到期商品和执行页的待决定商品也优先展示高优先条目，原冷静期照常生效。

购物原则在执行页直接添加和编辑。执行页填写商品，查看本地简报，选择快速决策或研究模式；开始后可保存研究记录，重启会恢复会话。AI 补充分析和问答需要点击才请求。确认购买时核对实际金额，并保存已确认的消费。

购买后任务页及到期提醒已移除，历史消费和评价保留。评价消费直接使用复盘页“标记一笔”。

## 蹲价格

清单中展开商品后，点击“价格记录”可追加手动价格、查看趋势、设置目标价和商品链接；再次点击商品行收起。价格信息集中在商品内，首页不再显示长通知。这里不自动获取商城价格，价格记录也不会生成支出。

## 记账与预算

从底部“账单”进入。

账单首页直接输入一句消费描述或上传截图，点击“AI 解析”，核对名称、金额与分类后再保存。也可切到“手动”，填写名称、金额、分类和可选备注后保存。消费金额须大于零，最多两位小数；补记可改日期。

首页只展示最近三笔，点开侧边详情可修改或删除。“查看当月全部”进入完整列表，支持筛选、双击修改及新增时填写具体时间，点击“返回记账”回到首页；删除确认默认取消。

点击“图表”默认打开消费日历，点日期查看当天摘要；“折线趋势”可切换本月每日／近六个月。右上角“记一笔”返回录入区。

选好分类和日期后点击“筛选”，才会改变列表。“重置”显示全部记录。页面上的“显示范围”代表已经应用的条件；没有结果时会显示提示。

从右侧“调整预算”打开编辑窗口。月度预算按年月保存，分别填写必要生活与自由消费预算后点击“保存预算”。标签显示数据库已保存的合计、全月已消费和剩余额度；输入框内尚未保存的数值不会改变额度。旧总预算尚未分配时有明确提示。首页突出自由消费剩余，并显示必要生活预留余额；单项或总额超支均会提示。预算、当前月分类汇总和全局金额不受列表筛选影响。

工作台侧栏显示支出最高的三个分类。商品、清单、执行与记账默认统一为吃喝、玩乐、服饰鞋包、交通、其他，记账另保留未分类。可从“设置 → 分类管理”新增、重命名、停用或重新启用自己的分类；历史记录保留原归属，详见 [分类管理](CATEGORIES.md)。

## 消费统计

在“账单”查看本月分类；点击“图表”，同页查看消费日历与折线趋势，趋势支持本月／近半年。切换月份会刷新对应数据，点击日期或趋势点可查看对应记录。复盘页聚焦消费感受与人格故事。

## 愿望清单

在“待购”页点击右上角“添加商品”，填写名称、预计价格、分类、优先级、冷静期天数和理由。新商品需明确选择高、中或低优先级；冷静期默认 3 天，即 72 小时，可设置 1 至 30 天。默认只显示待购商品，已购买／已放弃历史在“···”菜单中切换。点击商品行展开资料和购买、修改、放弃等操作，再次点击收起。

截止前不能购买；到期后点击“购买并记账”，确认实际金额、日期时间和备注。只有保存成功才改变愿望状态并产生消费，预算和统计同时更新。可以随时放弃，放弃金额不算支出。

修改待决定的愿望会重新开始冷静期。已购买或已放弃的条目保留为历史。删除愿望不会删除已记录的消费。旧版愿望升级后优先级默认为中。

## 数据管理

从设置进入“导入历史账单”，选择微信／支付宝 CSV、XLSX 或 Kura CSV。先选择或拖入文件，再核对名称和分类，最后点击底部“导入 N 笔”一次保存。分类无需逐项另行确认；搜索和“待核对”可帮助集中修改，批量分类只修改当前列表中勾选的记录。疑似重复默认不选，失败整批回滚。默认保留全部历史。examples 有虚构样例，建议在演示模式试用。

完整备份保存消费、预算、清单、截图、许愿池、原则、会话、商品资料、复盘、价格历史、导入索引和月度故事等业务数据，也保留旧品牌数据以兼容历史备份；API Key 不在备份中。恢复旧版备份时，该版本没有的新模块一并重置为空，恢复前的自动备份可用于撤回。

从右上角设置进入“数据管理”。

CSV 可导出全部已保存消费或已应用的筛选结果，包含完整备注。完整 SQLite 备份还包含预算和愿望，支持恢复。

恢复会整体替换业务数据，不是合并。程序先检查文件，显示各类数量，确认后先保存现有数据的自动备份，再恢复。筛选和未保存的预算输入会重置。自动备份路径在成功提示中可复制，可再选此文件撤回恢复操作。

存在打开的编辑表单时，请先保存或取消。文件不兼容、数据库被占用或恢复中途失败时，保留原数据并显示原因。

## 数据位置与常见问题

正式数据通常位于 `%LOCALAPPDATA%\Kura\KuraCpp\kura.sqlite`，状态栏悬停可查看实际路径。自动备份在数据库所在目录的 `backups` 中。程序升级沿用原数据。

不能启动时，检查是否完整解压并保留 `platforms/qwindows.dll`、`sqldrivers/qsqlite.dll` 和所有 DLL。数据库失败时先查看页面提示，关闭其他占用数据的程序后重试。保存失败时表单保留输入，不要重复新增已经提示保存成功的记录。

记账支持「按用途记／按预算记」切换并记住偏好。默认用途为吃喝、玩乐、服饰鞋包、交通、其他，也可选已启用的自定义分类；未选则为未分类。用途和预算归属分别选择，修改用途不自动改变预算。详见 [用途与预算分开记](EXPENSE_CLASSIFICATION.md)。

价格换算：打开「设置 → 价格换算」，选择学生或工作党并填写参考值。学生填写每日伙食费与餐数；工作党填写月到手工资、每月工作天数与每日工时。可用示例价格即时预览，保存后在商品价格旁显示餐费或工作时间参考；选择不开启并保存可隐藏提醒，已填数据保留。详见 [价格换算](PRICE_PERSPECTIVE.md)。

## 首次使用

普通启动在开屏后由小松鼠 Kura 打招呼，依次填写可跳过的 AI、月度双预算、价格换算、第一件心愿和消费原则，最后可选导入旧账单。确认的内容会真正保存，已有数据会预填；每一步可单独跳过，顶部“稍后再说”可结束。之后 Kura 会用高亮和气泡带你点击真实界面，不会替你记账或自动调用 AI。中途退出可续接，完成或结束后不再自动出现；随时可从「设置 → 关于与使用说明 → 重看新手引导」再次进入。详见 [首次使用与气泡教学](ONBOARDING.md)；本地记账、清单不需要配置 AI。
