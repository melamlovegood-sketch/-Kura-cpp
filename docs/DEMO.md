# Kura C++ 课堂演示步骤

运行 `Demo.cmd`，确认标题为“演示模式”。每次重新启动会创建新数据，因此可以重复练习，不使用正式数据库。

## 五至八分钟演示

1. 主页显示本月还能花 **63.00 元**，基础生活已花 **56 元**／额度 **100 元**，可支配已花 **181 元**／额度 **200 元**；许愿目标为机械键盘 **299 元**，已攒忍住金额 **45 元**。右上角设置可以切换暖色／冷色／深色。进入“账单”：当前月 7 笔消费，共 **237.00 元**，总预算 **300.00 元**，剩余 **63.00 元**。本月分类金额依次为餐饮 50、交通 6、购物 0、娱乐 45、学习 127、其他 9 元。
2. 将基础生活保持 **100 元**、可支配改为 **100 元**并保存，总预算变为 **200 元**，验证剩余 **-37.00 元**和超支提示。
3. 筛选“餐饮”，列表应有早餐和午饭两笔，共 **50.00 元**；预算与本月分类仍统计全部消费。重置筛选。
4. 新增一笔“饮料 / 8.50 / 餐饮”，填多行备注。本月变为 **245.50 元**。修改为 **6.50 元**后变为 **243.50 元**；先取消删除，再确认删除，回到 **237.00 元**。
5. 进入底部“复盘”：展示当前年 12 个月趋势、空月份、年度汇总，双击月份跳到记录页。切到“分类复盘”，查看本月学习类金额 **127 元**、**2 笔**、**53.6%**，以及与上月相比增加 **127 元**。历史月份随本机当前月份生成，不使用固定年月。
6. 进入愿望清单：包含冷静期中的机械键盘（高优先级）、已到期的蓝牙耳机、已放弃的摆件和已购买的专业书。键盘不能购买，耳机可购买。将耳机实际金额改为 **219.00 元**并保存，本月变为 **456.00 元**，愿望变为已购买且无法再次购买。
7. 从右上角设置进入“数据管理”：导出 CSV，保存完整备份；再改预算或新增消费，恢复备份，说明数量预览、默认取消和恢复前自动备份。
8. 将窗口缩为 800×600，展示分类面板自动改为纵向布局和页面滚动。关闭演示后重新打开，确认示例恢复初始状态。

## 导入与月度复盘演示

启动 Demo.cmd，进入设置 → 数据管理 → 导入历史账单，选择 examples/import-wechat.csv。核对分类后确认，默认新增 3 笔共 54.40 元；转账、退款和收入默认不导入。再选择同目录 XLSX，三笔会识别为重复。样例日期为 2026 年 10 月，查看该月复盘，给消费标记值得／后悔，再保存本地总结。真实 AI 可稍后配置，当前演示无需调用模型。

## 讲解要点

第三步演示：设置 → 购物原则与信任品牌，查看明确标注为虚构的示例；执行页输入一件商品，查看真实预算、原则和品牌组成的本地简报，选择快速决策或研究模式并开始。保存研究记录后关闭重开可继续；购买确认可选品牌，并生成 7／30 天任务。复盘页已有旧年度样例生成的两项到期任务，可填写评价并观察对应品牌权重变化。清单 → 蹲价格中机械键盘示例从 329 元降到 279 元，目标价 279 元；主页可看到提醒，“知道了”后保留已读状态。价格为虚构手动记录，没有商城自动抓取。

第二步流程可另行演示：主页点击“我现在想买……”，用“手动填写”录入奶茶 15 元并选择忍住，观察许愿池从 45 元变为 60 元，消费合计保持不变；再录入另一件商品选择加入清单或购买，分别核对清单和实际支出。配置个人 Key 后，可将手动填写换成文字／截图解析，确认后再选择。演示中的 Key 只在临时目录保存。

金额用整数“分”，显示时转换为元；汇总读取完整数据，不从筛选表格计算。购买用事务同时保存消费和愿望状态，恢复用事务同时替换三类数据。分类金额汇总保留 B 的原提交和测试，集成时兼容消费时间、备注及数据管理功能。

演示模式用于现场运行。持久化验收在自动测试的隔离数据库中进行；正式模式也可录入一条自建测试记录，关闭重开检查后再删除。不要为演示将虚构数据恢复到正式数据库。
