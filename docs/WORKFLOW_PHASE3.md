# 原版流程迁移 · 第三步

版本 0.11.0，日期 2026-10-27。使用原生 C++ / Qt 接入购买前决策、购物原则和品牌、购买后复盘，以及手动价格历史与站内提醒。

## 购物原则与信任品牌

设置 → “购物原则与信任品牌”。原则每行一条，最多 30 条，每条最多 500 字。保存失败保留原数据。正式模式不预填用户的个人原则或信任品牌；初次使用时可先添加一个自己熟悉的品牌。

品牌按细分类维护，可填写名称、权重（-100 至 100）和备注。同品类按规范化后的名称识别重复，区分不同品类。停用品牌不删除历史复盘；再次新增同品类、同名的停用品牌时恢复原编号和权重，避免丢失经验。执行页和购买确认表单只显示当前品类仍在使用的品牌。

## 执行与决策辅助

执行页填写商品、预计金额、品类，选择快速决策或研究模式。快速决策默认 15 分钟，允许 1 至 120 分钟并保留最近设置；研究模式显示已经进行的时间，使用可勾选清单和笔记，不强制倒计时结束。

点击“开始这次决策”才保存会话。同时最多一个进行中的会话。重启后恢复商品、模式、实际截止时间，以及已保存的清单、笔记和分析。关闭程序不会重新开始计时，计时到期只提示，不会下单或自动生成支出。研究记录需要点击保存，购买或结束会话前也会尝试保存；失败时保留界面内容。

本地简报使用真实的当月预算、当前许愿目标、前 10 条购物原则、当前品类按权重排列的前 5 个品牌及最多 3 笔同类历史消费。预计金额未知时不计算购买后余额；许愿池中的忍住金额不当作账户余额。金额较高时的研究模式建议是明确标注的本地提示，用户仍可自行选择。

“AI 补充分析”和“问问 AI”使用设置中保存的兼容接口。只在点击时请求，发送当前简报、问题及上一轮分析的有限文本；不包含 API Key 以外的其他凭据或数据库文件。AI 不能联网查实时价格，也不执行购买。回答是纯文本建议，金融记录仍由用户确认。预算、品牌或原则变化导致简报变化时，旧分析会清除；恢复备份会取消未返回的请求。

“决定好了，购买并记账”打开实际消费确认表单，可修正金额、日期、备注并选择购买品牌。取消表单不结束会话；保存时将会话结果、消费和两项复盘任务一起提交，失败全部回滚。重复提交已结束的会话不会再次记账。

“这次不买”或“尚未决定，先结束”只保存决策结果，不产生支出。若要记录忍住金额，可在主页另外明确选择“忍住”，不会把每次“不买”都当作实际收入。

## 7 天与 30 天购买后复盘

以下明确购买入口会安排两项任务：执行页购买、愿望清单中的“购买并记账”。统一输入中的“现在就买”只前往执行层，不记账、不安排任务。账单页普通新增、修改和历史导入不自动判作需要复盘的购买；升级也不批量给旧流水补任务。

按确认消费的日期和具体时间换算为 UTC，再加 7／30 个完整 24 小时。原消费没有具体时间时，仅提醒安排采用当地中午 12 点，不补造原消费时间。补记早期购买时，已经过期的任务会立即出现在待复盘中。复盘页同时展示未到期任务，但未到期不能填写。

复盘两题为使用频率（几乎不用／偶尔／每天）和值得度（后悔／一般／值得），另有可选备注。保存后“值得”给对应有效品牌权重加 1，“后悔”减 1，“一般”不改变，权重限制在 -100 至 100；停用品牌不继续加权。没有选品牌也能完成复盘，保留评价但不更新品牌。任务和权重在同一次事务中保存，每项任务只反馈一次。

完成历史保存当时商品、金额、品类和品牌名称快照。以后修改账单不重新安排任务；删除账单会取消尚未完成的任务，已完成复盘仍保留。主页显示到期提醒，底部复盘入口显示到期数量。站内提醒在打开、刷新或程序运行时更新，不代表系统推送。

## 蹲价格

清单页分为“待购清单／蹲价格”。可从统一输入选择“蹲一下价格”，或在蹲价格页手动新增。记录名称、品类、看到的价格、平台／来源和时间。同品类、规范化后完全同名的在跟踪商品会追加价格记录；变体商品应使用可区分的名称。

价格不会自动抓取。每个价格都来自用户确认的文字／截图或手动输入，界面标注来源和记录时间，不把价格记录当作消费。截图在这里用于提取价格；价格历史保存确认后的金额和来源，消费／愿望中的截图保存规则仍见 DECISION_FLOW.md。

可设置目标价、保存 HTTP／HTTPS 商品链接，并由用户点击打开。目标价设为零表示不设目标。趋势和明细展示最近 200 条已保存记录，只有一次记录时只显示一个点；全部历史仍在数据库和完整备份中。补记较早价格不会覆盖较新的最近价格。

最近价格低于上一条会产生站内降价提醒；最近价格不高于目标价时产生目标价提醒。“知道了”保存对该条价格的已读状态，重启后保持；以后新增符合条件的记录可再次提醒。结束追踪后停止提醒并保留历史，勾选“包含已结束追踪”可查看。

## 数据升级与完整恢复

在第二步五张表基础上新增购物原则、品牌、决策会话、复盘任务、价格商品、价格记录六张表，共十一张业务表。升级不删除旧消费、预算、愿望和忍住记录。完整备份包括这十一张表及自动编号；AI Key 和界面设置仍在独立加密设置文件中。

恢复先检查类型、范围、关联与状态，显示各类数量，再自动保存操作前备份。业务数据一次恢复，界面重新读取会话、复盘和价格；未完成的 AI 请求取消。兼容旧三表和五表完整备份，检查时只升级私有副本；旧备份没有的新模块恢复为空，避免残留恢复前的数据。未保存的预算和决策草稿会重置。

演示模式含明确标注为虚构的原则、品牌和价格样例；旧年度样例消费安排到期复盘，机械键盘的演示价格从 329 元降到 279 元，目标价为 279 元。示例不写入正式模式的数据。

## 验证边界

workflow_tests 覆盖规则保存回滚、品牌恢复、会话跨重启与重复购买保护、购买／复盘事务、复盘边界和一次性权重反馈、价格补记与提醒已读、十一表备份及旧五表恢复、真实界面操作和恢复时取消迟到的 AI 响应。AI 使用本机 HTTP 模拟服务验证实际 Qt 请求和文本回复，不使用个人 Key 或收费模型；真实服务仍需填写 Key 后联调。

自动商城抓价、云同步、系统推送、月度 AI 故事等原版其他扩展不属于本次实现。
