# 分类统一与分类管理

版本 0.17.0。

新建商品、清单、执行简报、价格记录、记账和导入核对共用默认分类：吃喝、玩乐、服饰鞋包、交通、其他，按此顺序优先显示。记账保留“未分类”作为未明确选择的状态；用途仍与必要生活／自由消费预算分开。

设置 → 分类管理中可新增自己的分类（名称 1–20 个可见字符，最多 40 个），保存名称、停用和重新启用。名称不可与默认分类或自己的其他分类重复。默认五类始终保留，自定义分类排在默认分类之后。

修改即时更新当前应用的分类选项，不清空记账草稿。重命名会在同一事务中同步已有消费、清单、执行、价格及商品资料的分类，不修改金额、编号或预算归属；失败整笔回滚。停用后新建记录不再提供该分类，已有记录继续显示、统计，编辑已有记录时也保留原归属。数据只属于当前账本，演示身份及其他账本彼此独立。

完整备份与恢复、CSV 导出再导入均保留自定义分类。旧备份缺少分类管理表时按空列表安全升级。旧的食堂／日常归入吃喝，交通归入交通，娱乐归入玩乐，其他旧商品分类在新建选项中统一归入其他；历史支出的网购仍保留未分类，不据购物渠道推断服饰用途。旧支出的预算归属不重算。

AI 新请求优先返回默认五类；仍兼容旧英文键及中文旧分类。自定义分类由用户明确选择。自动测试使用本地模拟服务，不调用真实 AI。

执行页移除“用文字或截图核对商品”快捷入口；保留商品名称直接填写、生成决策简报、从清单选择和购物原则。主页的购买入口继续使用独立商品核对流程。

category_management_tests 覆盖统一菜单、设置新增／重命名／停用、真实记账保存、旧数据迁移的编号与索引及自增序列、失败回滚、统计、CSV、完整备份、重启／账本隔离，以及三主题大字号预览。发布执行完整回归和源码指纹检查。
