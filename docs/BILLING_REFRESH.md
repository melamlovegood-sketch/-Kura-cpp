# 记账工作台（0.12.4）

账单首页按已确认的简洁样稿落地为原生 Qt 页面。首屏突出 AI／手动记账，只展示最近三笔消费；完整筛选、修改和删除从“查看当月全部”进入，并可返回工作台。点击最近记录，在侧边弹出的详情中查看时间、备注和截图，也可修改或删除。

- AI 记账支持文字或截图输入，解析后在页内修改名称、金额与分类，确认“保存这笔”后才写入数据库。取消等待保留输入；更改原文会使旧解析失效。调用沿用设置中已有的服务、型号和密钥。
- 手动输入名称、金额、细分类和可选备注即可保存。补记可选日期，非今日记录不编造具体时间。保存失败保留输入，成功后刷新最近记录、预算、日历和趋势。
- 图表通过“日历／本月趋势／近半年”直接切换。选择日历日期显示当天摘要，记录较多时可进入当天完整明细；趋势中选择某天或某月后，可打开对应范围的完整记录。图表汇总显示当前范围的金额和笔数。
- 记账视图采用居中单列：录入、最近三笔和一行预算摘要。摘要区可直接设置或调整预算；完整双预算和分类统计位于图表底部的“分类与预算”展开区。图表保持单列，展开区在小窗口内采用上下布局。月份、日期和分类使用统一主题的原生弹层。
- 导入账单连接原有导入预览及确认流程。恢复备份时取消未完成的 AI 请求并清除录入草稿。

数据库结构保持原样。自动验证使用临时数据库和本机 HTTP 模拟服务；真实 AI 服务及另一台 Windows 电脑需另行联调。`billing_tests` 验证月界与闰日、保存后重启、详情修改删除、筛选外记录操作、AI 确认和取消、数据库占用后重试、预算联动和三套主题的小窗口布局。截图由 `KURA_PREVIEW_DIR` 导出为 `billing-*.png`。

## 2026-10-28 · 聚焦记账

移除录入区重复引导语，导入账单改为次级文字入口。示例只在没有消费记录且输入为空时显示，输入文字、选择截图或保存第一笔后收起；切换到空月份不会重新出现。解析成功后，底部主按钮切换为“保存这笔”，修改原文后恢复“识别这一笔”。Ctrl+Enter 同样按当前步骤执行识别、确认保存或手动保存。切换图表、返回记账保留草稿和日期。预算摘要区分未设置、剩余和超支，并随月份及保存结果更新。

## 2026-10-28 · 聚焦图表

取消趋势视图中的第二层时间切换，三个图表入口处于同一层。图表居中展示，顶端只保留所选范围的一组总支出与笔数，近半年以所选月份为末月，明确标出起止年月。预算和分类默认折叠，展开后仍可调整预算。

趋势支持悬停、点击和左右键选择数据点。有记录时出现“查看当天／当月记录”；零记录点不显示空跳转。切换图表范围或月份清除旧的数据点选择；在记账与图表之间切换，以及查看明细后返回，会保留图表模式。界面截图位于 `build/preview/chart-focused/`。回归覆盖跨年半年范围、月份汇总、按所选日／月打开记录、空月份和三种主题的 800×600 布局。
