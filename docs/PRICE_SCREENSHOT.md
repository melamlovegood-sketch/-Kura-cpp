# 截图记录价格

清单 → 蹲价 → 添加商品，或展开商品 → 追加价格，均使用同一录入面板。

1. 可直接手动填写商品、金额、来源与时间，保存价格，不需要 AI 配置。
2. 也可选择图片、粘贴剪贴板截图或拖入图片，点击“AI 识别价格”。该操作才会将压缩截图发送到设置中的视觉模型。
3. 识别后核对表单及截图中的规格、券后条件。重要条件可补入来源栏。AI 不识别看到截图的时间，时间由用户确认或修改。
4. 没有唯一明确价格时金额显示“请填写价格”，补填前不能保存。追加记录保留原商品名与品类，同时展示识别出的商品名称，并要求确认同款同规格。
5. 点击“保存价格”才写入价格历史、刷新趋势和已有目标价提醒，不生成消费账单。关闭面板或取消识别不保存。

沿用已有 AI 地址、模型和密钥，不需要增加搜索服务或 MCP。截图用于本次识别，当前价格历史保存核对后的金额、来源和时间，不存储截图原文件。原有消费与待购截图保存行为保持不变。

`price_record_tests` 使用本地模拟服务验证截图请求、识别后不自动写入、人工修改、重复保存防护、追加记录身份核对、空金额补填、取消/失败后手动录入以及两个界面入口。真实模型识别质量需结合实际商品截图核对。
