# 购买流程精简（2026-10-28）

主页和执行页的“我现在想买……”现在打开同一个购买弹窗。

1. 输入商品：文字、截图或手动填写。AI 下一步只产生草稿；没有 AI 配置时可直接手填。
2. 核对信息：名称、金额、分类。品牌、备注与商品详情默认收起。
3. 选择去向：加入清单、购买并记账、这次不买。蹲价与继续研究作为次级入口。

选择购买后才显示购买日期，选择清单后才显示冷静期。选择不会写入数据，底部确认按钮完成提交。上一步保留草稿和分支设置；原始输入或截图变化后需要重新核对。金额尚未确定时仍可继续研究，实际购买、加入清单、记忍住金额和蹲价要求有效金额。

“继续研究”将名称、金额、分类、品牌、备注、截图与商品资料带入执行页，点击开始后才创建决策会话。已有进行中会话时不能覆盖。研究路径中的截图会随商品资料保存，重启后可用于后续购买和加入清单。购买沿用记账与 7 天／30 天复盘；这次不买沿用许愿池忍住金额记录；蹲价只记录价格。

验证覆盖：两个入口、按步骤显示、分支互斥、返回保留草稿、AI 初稿、手动填写、清单冷静期、购买日期、重复提交、写入失败后重试、研究交接及已有会话保护。三种主题和小窗口截图位于 `build/preview/purchase-flow/`。

验证结果：Release 编译通过；decision、execution_ui、product_details、workflow、shell、decision_chat、dialog 共 7 组相关回归全部通过。
