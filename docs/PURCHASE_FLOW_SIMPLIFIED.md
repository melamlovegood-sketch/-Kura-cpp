# 购买流程精简（2026-10-28）

主页和执行页的“我现在想买……”现在打开同一个购买弹窗。

1. 输入商品：文字、截图或手动填写。AI 下一步只产生草稿；没有 AI 配置时可直接手填。
2. 核对信息：名称、金额、分类。品牌、备注与商品详情默认收起。
3. 选择去向：加入清单、现在就买、这次不买。蹲价与继续研究作为次级入口。

“现在就买”点击一次即携带商品资料进入执行层，不显示购买日期、不生成消费或复盘任务，避免和后续导入账单重复。选择清单后才显示冷静期；清单、不买和蹲价由底部确认按钮提交。上一步保留草稿和分支设置；原始输入或截图变化后需要重新核对。金额尚未确定时也可前往执行层；加入清单、记忍住金额和蹲价要求有效金额。

“现在就买”和“继续研究”共用交接，将名称、金额、分类、品牌、备注、截图与商品资料带入执行页，点击开始后才创建决策会话。已有进行中会话时两个入口均不可用，不会覆盖原决策。交接失败时保留弹窗和资料供重试。截图会随商品资料保存，重启后可用于后续购买和加入清单。这次不买沿用许愿池忍住金额记录；蹲价只记录价格。执行层内单独确认的购买记账流程保持原有行为。

验证覆盖：两个入口、按步骤显示、分支互斥、返回保留草稿、AI 初稿、手动填写、清单冷静期、重复提交、写入失败后重试、现在就买及研究交接、不记账与已有会话保护。三种主题和小窗口截图可用 `KURA_PREVIEW_DIR` 生成。
