# 执行页简洁版

清单商品的决策入口仅显示已结束冷静期的待决定商品，最多三件，优先级高的在前，同级新添加的在前。点击「去决策」自动带入已有商品信息并进入快速／研究模式选择，用户点开始后才创建会话。点击及开始均复核是否仍符合条件；已有进行中的决策不会被覆盖。购买／放弃处理原清单条目，继续等等保留原条目，不重置冷静期或重复添加。来源关联跨重启、备份恢复保留，旧备份自动兼容。

执行首屏采用双栏工作台：左侧保留直接输入、示例快捷填入与商品截图核对，下面展示最多三件冷静期已结束的真实待决定商品（优先级、金额和「去决策」入口）；右侧完整展示个人购物原则。宽窗口并排，窄窗口上下排列，不虚构商品或自动修改原则。查看全部沿用清单入口，结束冷静期不自动购买。无符合条件的商品时显示简短空状态；进入简报和决策后收起待决定区。暖色、冷色／深色和大字号均适配。`execution_ui_tests::entryWorkspaceUsesRealWishesAndReflows` 验证真实数据、排序、过滤、状态、空状态、草稿、三套主题和窄窗口。

金额输入修复：从未填写预计金额的决策进入「加入清单」时，价格框获得焦点会清除零金额的提示文字，直接点击即可输入数字；失焦且未填写时仍保留提示。真实鼠标／键盘回归覆盖快速、研究模式的首次填写与空金额报错后补填，确认输入 `29.90` 后保存为 `2990` 分，且当前决策正常结束。

决策操作区现在并列显示「加入清单，稍后再想」「已决定购买」「放弃购买」，窄窗口纵向排列。「放弃购买」从预算参考下方移到主要操作区，沿用已有不买结果（`skipped`），保存研究记录并结束当前决策，不生成消费或待购条目；「先结束，尚未决定」仍是独立的次级操作。快速模式在倒计时结束或提前决策后显示三项选择，研究模式直接显示。回归覆盖两种模式、有／无金额、宽／窄布局及不买结果持久化。

首屏只有小标题「执行层」和两张卡片：「买什么？」的单一输入框，以及默认展开的「购物原则」。空输入时提交按钮禁用，填写商品名后点击「生成决策简报」或按回车，才出现下一屏。移除英文标语、大标题、01／02／03 编号、提前出现的模式与计时状态。购物原则在执行页直接添加、编辑并保存在本机，设置页不再提供独立入口。

提交后显示简短的「决策简报」和「决策模式」两张卡片。金额、用途、品类、品牌位于可选补充中，不要求先填写金额；可通过「重新输入」返回。模式建议沿用原网页：预计金额大于 500 元，或名称包含数码／电子类关键词时建议研究模式，否则建议快速决策，用户可以自行选择。进入简报不会创建决策会话，也不自动调用付费 AI。

点击「开始」后才出现当前模式的内容。快速模式显示倒计时和「提前决策」，倒计时结束或主动提前决策后出现最终操作；不会自动购买。研究模式显示三项确认和可选研究记录。开始后可在两种模式间切换，保留会话编号、记录和原有截止时间，重启恢复当前模式。未填写金额时不显示大号「金额待确认」或空预算面板；填写后按真实的基础生活／可支配品类计算影响。AI 问答与预算参考默认折叠。

点击「修改商品」可以更新当前决策的名称、用途、金额和品类，不重新开始计时。用途与品牌选择存入现有研究记录 JSON，兼容旧记录，不新增数据库字段。研究勾选立即保存，文字记录使用保存按钮，切换步骤与做决定前也会保存。

「加入清单，稍后再想」打开预填当前商品的确认表单。取消不写入愿望，也不结束决策。确认时，愿望新增与当前会话结束作为一个 SQLite 事务提交；失败回滚，重复提交不会重复新增。该操作不产生消费。购买仍由既有确认表单填写实际金额，成功后记账并安排后续复盘。

暖色、冷色、深色沿用统一主题，内容宽度与主页、清单等主页面共用 1040px 画布（含左右内边距）。小窗口使用页面滚动，底部导航保持可用。`execution_ui_tests` 覆盖初始渐进显示、仅输入商品名、购物原则保存与取消、两种模式切换、过期计时不产生消费、预算变化、重启恢复、加入清单事务和小窗口布局。既有 workflow／shell 测试继续覆盖购买、AI 上下文与外壳导航。
