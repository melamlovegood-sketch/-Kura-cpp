# 栗子收藏室

复盘页的「值得／后悔」榜单下方展示紧凑的徽章收藏册。宽窗口六列两行，中等窗口四列，窄窗口三列或两列；大字号时根据文字宽度自动减少列数。每枚高 112px、图案 48px，取消独立卡片边框和长进度条；只保留名称，以及已收藏的小勾／未解锁的进度。选中时只在栗子周围显示光圈，键盘焦点有独立提示。

点击或用键盘选中栗子，底部简短详情显示分组、解锁条件、文案和收藏日期，窄窗口自然换行。三套主题共用原生栗子图案，未收藏时为轮廓，已收藏时填色。收藏规则和已有进度保持不变。

## 统计与保存

- 读取收藏时同步历史记录，范围不受复盘当前月份限制。天数按不同消费日期统计，不是打开应用的日期，也不要求连续；同日多笔只计一天，未来日期不提前计入天数。
- 同步过的证据存入本机数据库 `achievement_marks`，每枚达到目标即停止收集。已统计的日期、评价和决策不会因原记录修改／删除而倒扣；修改同一笔评价不重复计数，也不因月份切换、中断或重启清零。
- 不买／放弃按去除首尾空格、忽略英文大小写后的商品名去重，首页“这次不买”、执行会话和清单共用去重键；首页记录中的理由不参与去重。“暂不决定”不算放弃，旧蹲价归档也不算。首次收藏日期是本版本首次确认条件达成的日期，历史数据不会伪造过去的解锁时间。
- 未设置预算、自由消费额度为零、只有标记但没有理由，都不会解锁对应成就。无消费日期不会被自动视作“自律日”，省下的金额也不会用作积分。
- 数据库不可用或刷新失败时显示明确状态；成就失败不影响原有消费故事／榜单。没有网络请求、积分商店或额外弹窗。
- 完整备份携带收藏证据；恢复会替换为备份当时的收藏状态。旧备份没有成就表时安全升级，再从其中的业务记录计算收藏。

`achievement_tests` 验证累计与去重、冷静期边界、历史归档排除、理由要求、跨月与重启、备份往返／旧备份升级／无效证据拒绝、布局与主题。所有数据来自临时模拟数据库。

## 解锁时的反馈

保存成功并首次达成成就后，自动出现暖纸色居中卡片：原生栗子印章、成就名称、文楷寄语、达成条件和陶土色「收好这颗栗子」按钮。轻柔渐显遵循「减少动画」设置；夜间／冷色主题、130% 字号与窄窗口同步适配。内容过多时只滚动卡片正文，关闭与收藏按钮保持可见。

同一次操作的多个成就合并展示；表单、确认框、开屏与首次引导结束后再展示，不覆盖进行中的输入。可点按钮、右上角、遮罩或 Esc 关闭，「去栗子收藏室看看」直达复盘收藏区。关闭、切页与重启不重复弹出；已有账户启动和完整备份恢复静默建立基线，不把历史成就当成刚解锁。

主窗口统一观察 SQLite 本连接修改计数与外部提交版本；无变化时只读计数，变化后沿用原有成就仓库事务判定，不调用 AI。失败不推进通知快照，稍后重试。
