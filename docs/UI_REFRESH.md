## 2026-10-27 · 字体与视觉对齐

参照同级 `Kura/src/index.css`、`AppLayout.tsx`、`BudgetCard.tsx` 和 `WishPoolCard.tsx` 对齐原版视觉，而不是只沿用近似的暖色背景。

- 随 Qt 资源内嵌 DM Sans 和 DM Serif Display，不依赖联网、系统预装或运行目录中的独立字体文件。正文使用 DM Sans，品牌与大金额使用 DM Serif Display；中文按 PingFang SC、Microsoft YaHei UI、Microsoft YaHei 回退。两款字体的 OFL 授权位于 `resources/fonts`，打包时附带。
- 暖色、冷色、夜间的页面、卡片、文字层级、边框和进度颜色与原版 CSS 变量一致。正文 13px、辅助文字 12px、栏目 11px、标题 16px；首页金额 52px，品牌 22px。
- 首页和设置采用 640px 居中容器、左右 24px 留白。首页卡片内边距 18×16px、间隔 12px，许愿池使用原版的浅底色。移除额外口号、重复标题与厚重按钮，操作入口保持可用。
- 页头高 52px、导航高 68px；导航以图标和文字颜色表达选中状态。购买入口宽度 592px，与首页卡片对齐。进度条改为 2px 细线。
- 账单、清单和统计保留现有数据表格及操作，统一字体、标题、按钮与细分隔线。Qt 原生控件与网页的字形渲染和半像素边框仍可能有细微差异。

## 已接入的页面

| 入口 | 当前行为 |
|---|---|
| 主页 | 默认打开；展示本月真实预算、已花和剩余、预算使用进度，以及待决定愿望和到期提醒 |
| 账单 | 既有消费增删改查、筛选、预算和本月分类金额 |
| 清单 | 既有愿望、优先级、冷静期、购买记账、放弃历史 |
| 执行 | 两个可用入口：直接新增实际消费，或加入冷静期愿望清单 |
| 复盘 | 既有年度支出趋势、月度明细和分类对比；月份跳转回账单 |
| 设置 | 暖色、冷色、深色即时切换与保存；进入数据管理 |
| 数据管理 | 既有 CSV、完整备份、恢复；可返回设置 |

页头为 KURA 品牌与设置，页尾是固定的五个导航。主页购买入口固定在内容与导航之间。首页与设置限制内容宽度，账单、清单和统计使用较宽空间；小窗口通过页面滚动访问内容，导航始终保留。

## 数据与状态

原业务数据库结构与整数金额规则不变。首页每次进入时重读本月预算及愿望，消费变动后也刷新；首页可见时每分钟刷新，跨日及冷静期到期后更新。任一查询失败时保留上次首页数据并显示错误，不显示伪造的零。未设置预算与明确零额度分别处理。

主题保存在数据库路径加 `.ui.ini` 的独立配置文件里，默认暖色，无效主题回退暖色；保存失败有提示。使用显式临时数据库的测试、演示与正式数据隔离。业务备份不包含外观偏好。切换导航或主题不重建业务页面，保留预算草稿、筛选和选中记录。
