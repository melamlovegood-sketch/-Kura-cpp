# 主页面布局

主页、账单、清单、执行和复盘共用 `ShellWidgets::PageWidth`（1040 逻辑像素）的居中内容框，左右内边距 28，顶部 24，底部 32，主要模块间距 20。标题保留 42 高度，缩放时使用 Qt 逻辑尺寸。

- 主页：采用行动首页，宽度达到 880 时预算与「许愿池」在上方并排，窄窗口按预算、许愿池顺序排列；购买入口在标题右侧。预算突出自由消费剩余，必要生活剩余和合计已花作为紧凑补充。下方仅在有数据时显示「继续上次分析」和「等过之后，再看一眼」；后者按冷静期结束时间展示最多两件商品，点击直接进入待决定筛选并展开对应商品，查看全部进入同一筛选。移除价格长通知和清单数量卡片，价格仍在清单商品的价格记录中查看。许愿池使用「忍住金额累计」表述，查看目标直接打开商品资料，更换目标仍进入清单。
- 账单：宽度达到 960 时记账与最近记录在主栏，300 宽的预算／分类侧栏在右；小窗口回到上下布局。图表仍保留日历和趋势的独立范围与交互。
- 清单：标题、添加入口和商品列表沿用公共边界；商品行基准高度 88，文字与价格换算可以按内容增高，展开详情继续使用原操作。
- 执行：输入页达到 880 时把购物原则放到 300 宽的右栏；窄窗口上下排列。进入简报或决策后隐藏原则栏，仍只展示当前步骤，不预留隐藏步骤高度。
- 复盘：标题后先展示三个本月数字，再展示故事和评价。故事正文最长 760，避免宽窗口下单行过长；下方扩展内容继续沿用公共内容框。

顶部品牌栏 46，底部导航 60。内容在滚动区域内布局，固定导航不覆盖正文。设置与数据管理保留各自适合表单的阅读宽度。

`shell_tests::primaryPagesShareCanvasAndReflow` 验证五页标题起点、内容宽度、800×600 下无横向滚动、首页／执行栏位重排、购买入口位置和复盘数字顺序。已有页面功能、主题与滚动测试继续参与完整回归；本次验证使用临时数据库及本地模拟 AI。
