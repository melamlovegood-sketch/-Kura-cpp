# 月度消费人格故事 · 0.12.6

日期：2026-10-28。内置人格、提示词、结构校验与本地版本集中在 `src/MonthlyStoryTemplate.cpp`。

| 人格 | 叙述方向 | 本地候选依据 |
|---|---|---|
| 松鼠型 | 给心动留冷静期 | 至少两次明确的忍住记录 |
| 海狸型 | 用途清晰，一点点搭建生活 | 至少两笔工具设备，或明确标记值得且说明常用、解决问题的消费 |
| 猫咪型 | 熟悉而稳定的日常 | 至少三笔餐饮／日用品／日常消费，合计达到本月记录金额的一半 |
| 水獭型 | 兴趣与快乐 | 至少两笔娱乐记录 |
| 猫头鹰型 | 学习与成长投入 | 至少两笔有品名或备注支持的教材、课程、书籍等记录，不只依赖旧“学习”分类 |
| 候鸟型 | 多种生活场景 | 至少五笔、三个分类，单个分类金额占比不超过55%；不据此编造旅行 |

除松鼠外，固定候选识别需至少五笔记录或两笔值得评价。有固定候选时必须从中选择，不再附带“待解锁”选项；没有固定候选时使用 `custom`，由AI为当月记录创作2～12字、以“型”结尾的专属称号，如“心愿收藏家型”“烟火小猫型”。只要有消费、忍住或放弃购买记录，就一定有人格；完全没有记录才显示空状态。候选只是对本月记录的观察，不是固定人格，不按金额多少评优劣。

AI 从候选中选择一位主角，填写动态小称号、标题、短故事、可选小插曲、下月小任务。提示词建议故事120～180字、最多两段；客户端最大240字，标题28字、小称号18字、插曲50字、任务40字，避免报告式长文撑满页面。无小插曲时不占位置。

请求包含当前与上月汇总、个人评价、最多12笔经过挑选的消费简要信息。消费备注与评价理由各截取160字；不会发送完整历史流水。商品名及备注始终视为数据。人格候选、样本引用编号与结构在响应后再次校验，非法结果不覆盖原故事。没有标记不等于没有感受，没有记录不等于没有发生；不推断收入、购买动机、使用经历，不把忍住金额写成实际收入。

新故事使用 `schema_version:2`，增加 `persona_name` 保存专属称号；固定人格该字段为空。仍保存在既有 `monthly_stories.story` 文本列中，不新增数据库表，完整备份继续保存。v1与旧纯文本故事可阅读，长文只预览220字，全文单独打开。旧“待解锁”故事在首页替换为明确标注来源的本地人格预览，不自动联网重写；点击重新生成后保存正式故事。

记录变化后，首页收起旧正文，显示基于最新记录的本地人格预览及更新提示。“查看上次故事”在单独窗口显示保存时间及旧记录提示，避免旧金额与当前概览混在一起。生成期间切月、改动数据或恢复备份时，沿用取消及事实指纹检查。

无需AI时，“更多 → 生成本地总结”也使用同一张人格卡结构，并明确标注本地来源。

验证：`monthly_review_tests` 覆盖六种候选、稀疏记录、样本数量、响应限制、无效引用、持久化、备注变更及备份恢复；`review_layout_tests` 检查三种主题、小窗口、旧长文与过期故事；`supplement_ui_tests` 通过本机模拟服务检查内置提示词、真实请求、异常人格保留旧故事及取消恢复流程。
