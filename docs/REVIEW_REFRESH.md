# 复盘首页简化 · 0.12.2

按照确认的网页样板，用原生 Qt Widgets 调整月度复盘，没有新增数据库表。

- 首页只显示月度故事、三个数字和一个可切换的值得／后悔列表；不再展开画像、分类表及高光卡片。
- 月份选择放在标题右侧，保留直接编辑年月和跨年切换。读取失败时恢复原月份，保留上次成功的故事和数字。
- 故事默认显示最多 100 字摘要，点击“展开全文”后显示完整正文、小插曲和下月任务，可再次收起。切换月份、生成新故事或故事过期时恢复短版；全文可选中复制，旧版故事的短首行作为标题。
- 首次“生成本月故事”保留在故事卡片中；已有故事的“重新生成故事（AI）”收进更多菜单。“更多 → 生成本地总结”无需联网；取消按钮仅在生成期间显示。
- 值得与后悔按金额展示各自前五项，显示实际名称、个人理由、金额和消费日期，保留独立的标记编辑流程。
- 到期的购买后复盘在标题下方显示一行数量和入口，无到期任务时隐藏，完成复盘后同步更新。“购买后复盘”“年度与分类统计”的常规入口保留在底部，进入后可返回原月份；统计入口同步所选年月。
- 暖色、冷色、深色共用主题令牌。小窗口只滚动内容，底部主导航保持可用。

验证由 `review_layout_tests` 和既有 `supplement_ui_tests` 等测试覆盖；截图命名为 `build/preview/review-refresh-*.png`。
