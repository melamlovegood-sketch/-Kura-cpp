# Kura 美学与排版规范

版本 0.16.0 · 2026-10-28

## 设计方向

像一本能随手记下生活的小册子：界面保持精确，表达带有温度。借鉴 Anthropic 的纸张、墨色、编辑式排版与克制强调，保留 Kura 的松鼠标识与消费决策定位。操作区优先清晰和效率，寄语与故事承载情感。

## 字体与信息层级

| 角色 | 字体栈（从前到后） | 标准字号／字重 |
|---|---|---|
| 通用 UI、正文 | DM Sans / Source Han Sans CN VF / Microsoft YaHei / PingFang SC | 14px / 400 |
| 功能页标题 | 同 UI | 20px / 500 |
| 首页寄语 | DM Serif Display / LXGW WenKai Lite / Source Han Sans CN VF | 26px / 400 |
| 月度故事标题、执行引导 | 同寄语 | 24px / 400 |
| 商品名称 | 同 UI | 15px / 500 |
| 长文阅读 | 同 UI | 15px / 400 |
| 辅助、日期、操作说明 | 同 UI | 通常 12–13px / 400 |
| 品牌与主金额 | DM Serif Display / Source Han Sans CN VF / Microsoft YaHei | 品牌 22px、主金额 52px / 400 |

文楷只用于少量标题与许愿目标，不进入输入框、账单明细、分类选择和导航。金额中的中文“约”使用黑体，避免功能信息过度装饰。中文不套用英文全大写标题的宽字距。中英文栈均以拉丁字体在前；Qt 通过字形回退分流，不使用网页的 unicode-range。

100／115／130% 沿用既有字号设置；不安装系统字体。所有字体资源内嵌，详情和授权见 `resources/fonts/README.md`。显式指定变量字体 wght，DM Sans 同时设置 opsz；不能以“字体族名字正确”代替实际 glyph run 检查。

## 颜色与表面

颜色由 `AppTheme` 的统一角色提供；控件 QSS 使用角色替换、自绘控件使用 `AppTheme::color()`。

| 角色 | 暖色 | 夜间 |
|---|---|---|
| page | #f7f3eb | #211e1a |
| card | #fffcf6 | #2a2621 |
| inset | #eee6d9 | #332e27 |
| ink | #352f28 | #f1e9dc |
| secondary | #685e52 | #c6baaa |
| muted / placeholder | #706557 | #b3a694 |
| border | #dfd6c8 | #494034 |
| accent | #a64f35 | #e3ac8b |
| onAccent | #fffcf6 | #2a2019 |
| highlight | #f0ddcc | #49382b |

橙色用于主要行动、选中态、焦点与少量编辑式强调。错误、警告、成功保留语义色；执行决策保留原有低饱和绿色语义。首页购买入口保留墨色按钮。冷色偏好继续提供，和夜间、暖色共享排版规则，同时改善辅助文字对比度。

不用颗粒图、背景图片、大面积渐变或发光阴影。低分辨率桌面上用三层纯色表面、1px 边界和内容间距表达纸张层次，确保账单不被装饰干扰。

## 布局与控件

- 五个主要页面沿用 1040px 最大内容宽度、28px 页面左右边距、24px 模块间距。保留既有并排／上下重排规则。
- 通用卡片内边距 22px × 20px，内容间距 14px；故事卡保留更宽的阅读留白。主要圆角 14–16px，表单 9px，菜单 10px。
- 首页寄语允许换行，不挤掉购买入口。内容随高度滚动，固定导航不覆盖正文；800×600 与大字号下不产生水平滚动。
- 导航选中项同时使用浅色底、文字和图标颜色表达当前位置。鼠标悬停、键盘焦点和禁用状态独立可辨。
- 进度线统一 4px；许愿进度使用主题角色，夜间不遗留明黄色底。菜单、输入框、弹窗沿用同一纸张／边框系统。
- 表单、真实数据、决策闭环、键盘快捷键和现有弹窗管理流程继续保留。

## 阅读与交互

AI 回答使用 QTextBlockFormat 的 170% 行高，段间距 14px、列表 8px；仍禁用模型提供的远程资源加载。月度故事使用 175% 行高，保持最长 760px 阅读宽度、展开／收起和原文本语义。可复制内容保留文本选择。

使用既有开屏和进度动画，尊重“减少动画”；不增加阻塞操作的页面过渡。避免淡入未完成时截图、文本发虚或输入焦点跳动。

## 验收

- `typography_tests`：离线字体存在、实际中英文字形分流、Normal／Medium 字重、DM Sans 变量轴、晚创建弹窗及切换主题后的解析；三主题 ink／secondary／muted 在 page／card／inset 上和主按钮文本至少 4.5:1。
- `shell_tests::editorialPagesFitAtLargeScale`：三套主题 × 100／115／130% × 五个主页，800×600 无水平滚动，寄语没有被固定高度裁切。
- 既有 shell／settings／dialog／execution／planning／monthly-review 等完整回归继续参与；可通过 KURA_PREVIEW_DIR 导出真实 Qt 页面截图做视觉检查。
- 最终使用 `scripts/Build-Unified.ps1` 完整编译、回归、源码指纹复核后才更新根目录固定启动入口；历史预览不作为最新版。
