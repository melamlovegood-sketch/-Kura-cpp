# 应用内弹窗与选择器

应用内的清单、记账、决策、价格、购物原则、复盘、历史明细、账单导入与预算编辑共用 `DialogUi` 弹窗框架。它在首次显示前接入现有对话框，不替换保存、取消、验证或数据库操作。

- 暖色采用米白、暖灰与柔和陶土色，沿用应用字体和冷／深色主题。业务弹窗使用原生圆角区域裁切，卡片贴合窗口边界，移除可能在 Windows 上变黑的透明外边距和阴影底板。自绘标题和关闭按钮。标题区可以拖动，Esc 取消；删除、恢复等确认仍默认取消。
- 背景遮罩随弹窗打开、关闭及所属窗口尺寸变化更新；嵌套确认只关闭自身，外层表单继续保留。
- 表单内容独立滚动，末尾保存／取消区固定。尺寸按当前窗口与屏幕可用区域限制，避免小屏幕无法触及保存按钮。
- 加入清单按名称、金额、分类／优先级、冷静期和理由分组。3／7／14 天可一键选择，也可以填写 1—30 天；校验失败显示就地错误并聚焦相应输入，保存失败保留已填内容。
- 分类、品牌、优先级等统一使用应用内选择弹层。较长列表支持搜索、滚动和上下键导航，Enter 选择、Esc 关闭。日期选择支持月份网格、年份输入、键盘确认与返回今天。
- 数值字段保留键盘输入，去掉狭窄的系统上下箭头。文件选取继续使用 Windows 文件选择器，业务表单和确认界面使用应用样式。

`dialog_tests` 使用临时数据库检查表单验证、冷静期快捷选项、保存状态、三套主题、嵌套确认、遮罩回收、小窗口滚动和固定操作区。通过 `KURA_DIALOG_PREVIEW_DIR` 导出 `dialog-*.png` 原生 Qt 截图。

账单导入现采用选择文件／核对账单／完成三步。空状态支持拖入文件；核对列表提供搜索、待核对和重复异常筛选，分类按需打开编辑器，批量分类仅作用于当前列表中已勾选的记录。最终导入按钮即表示接受当前名称与分类，不再逐笔额外确认；写入仍为整批事务，失败保留预览。导入选项变更后自动重新读取。导入表格自身滚动，底部金额和保存入口固定。
