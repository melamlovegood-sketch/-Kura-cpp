# 设置与备份

设置首页包含外观、价格换算、分类管理、AI 服务和数据管理；按使用偏好与服务数据分组。右侧显示当前保存状态，底部提供问题反馈、关于与使用说明；关于页展示构建版本，支持复制版本信息。实际版本由 CMake 项目版本生成，命令行 --version 与界面一致。

## 外观

暖色、冷色、夜间主题或跟随系统。跟随系统在系统切换深浅模式时更新；浅色使用暖色。字号提供标准 100%、大 115%、特大 130%，即时应用并记住选择。减少动画跳过下一次开屏，并直接显示许愿池进度。

## AI 服务

配置服务地址、模型和 API Key，密钥可临时显示，离开子页后重新隐藏。修改有明确的未保存提示，返回设置首页后可继续编辑，切页保留草稿。保存不会自动调用模型。

文字与虚构截图测试继续独立进行，显示最近测试时间。测试结果与服务地址、模型及密钥的配置指纹匹配；更换配置不会沿用其他配置的成功结果。保存配置仅显示已配置，不表示连接或图像能力已通过验证。测试会实际调用用户配置的服务；自动化回归只使用本机模拟服务。

## 备份

数据管理 → 备份数据提供手动备份和自动备份设置。自动备份默认关闭；开启时立即尝试备份，此后每天首次启动时保存一份，保留 1–30 份（默认 7 份）。同日重复启动不生成重复快照；若失败，不更新成功时间，之后可重试。自动备份包含完整业务数据库，恢复使用原有备份检查、确认和恢复前保护备份。

自动备份存放在数据库同目录的 `<数据库文件名>.backups/` 中。轮换只清理本功能生成并匹配命名格式的普通文件，保留最新成功快照，不删除手动备份或链接。可打开数据和自动备份文件夹。备份在本机，不等同于云端或异机副本；可另存手动备份到其他设备。密钥、外观、价格换算及自动备份偏好仍在本机设置文件中，不加入业务备份。

## 购物原则与品牌

购物原则在执行页展开后直接添加、编辑，保存后立即更新本地简报和后续 AI 上下文。设置页不再提供独立编辑入口。

信任品牌管理、购买选择、权重展示和 AI 偏好参考已移除，旧购买反馈不再调整品牌权重。已有品牌表和历史关联仅用于原数据库及备份的兼容读取，不再展示给用户。商品资料里的品牌字段是商品本身的事实信息，继续保留。

## 验证

`settings_tests` 检查主题跟随、字号和动画偏好重启保持、设置摘要、AI 草稿和配置测试结果隔离、执行页原则持久化、信任品牌退出上下文、自动备份每日去重／轮换／恢复／失败重试，以及三套主题和窄窗口大字号布局。发布仍须通过 `scripts/Build-Unified.ps1` 的完整回归与源码指纹校验。

## 问题反馈

设置首页底部的“问题反馈”展示联系邮箱 `meilintan@bupt.edu.cn`。支持选择并复制邮箱，或点击“写邮件反馈”打开系统邮件应用；预填反馈标题、当前版本和问题描述／操作步骤，邮件由使用者填写并自行发送。无法打开邮件应用时提示复制邮箱后手动发送。

## 分类管理

默认五类优先显示，并支持新增、重命名、停用和重新启用自己的分类。详见 [分类统一与分类管理](CATEGORIES.md)。
