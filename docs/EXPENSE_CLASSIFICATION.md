# 用途与预算分开记

用途回答「花在什么上」，预算归属回答「从哪笔预算出」。两项分别保存；更改用途不改变预算归属。

- 用途：吃喝、玩乐、服饰鞋包、出行、其他；未选时为未分类，与主动选择其他不同。
- 预算归属：必要生活（基本吃饭、通勤、日用品等预留）／自由消费（自己决定的非必需消费，也可不花）。
- 按用途记：用途优先，预算归属始终可见。按预算记：预算归属优先，用途可按需补充。
- 记住上次模式，切换不清空金额、名称、用途、归属、日期、备注或截图；保存只生成一笔账。名称可留空，保存为「一笔支出」。
- 首页突出本月自由消费剩余，必要生活余额单独显示；两项预算不自动挪用。
- 导入可分别修改用途、归属；批量选择可保持其中一项不变。AI 给建议，用户确认后保存。
- 用途分类不表达金额大小：399 元的鞋仍是服饰鞋包，可按实际用途选择任一预算。本次不新增大额阈值或提醒。

## 旧数据

新增 transactions.purpose_category 与 budget_scope 两列；空值表示沿用历史映射，原分类列、金额与编号不重写。食堂／日常转为吃喝，交通转为出行，娱乐转为玩乐；日用、订阅、学习等归其他；旧网购归未分类。历史预算归属沿用原规则，编辑后按用户明确选择保存。

原商品目录继续服务清单、品牌和研究资料；实际购买记账时单独确认用途与预算。旧商品目录不再决定已保存支出的预算统计。

CSV 保留原分类列以兼容旧文件，追加消费用途并保存独立预算归属；新版本重新导入时读取两项。旧备份升级后可恢复，新备份包含独立字段。
