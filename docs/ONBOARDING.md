# 首次使用与气泡教学

桌面版沿用原网页的初始设置顺序，在前面增加小松鼠 Kura 的欢迎页，在后面增加真实界面的气泡教学。设置区覆盖整个主窗口，纸色背景、居中窄栏、逐步填写；适配暖色、冷色、夜间主题及字号设置。

1. Kura 打招呼，介绍记账、冷静决策、许愿池和复盘。
2. AI：选择千问／OpenAI／自定义兼容服务，填写 Key，或选择当前包可用的试用。确认仅保存；测试连接是独立操作，只发送一条虚构问候。密钥沿用本机加密存储。可以跳过，离线记账和清单仍可用。
3. 本月预算：分别填写必要生活和自由消费，确认保存至当前月份。已有预算预填，跳过不改动。
4. 价格换算：复用设置中的学生／工作党／不开启及对应字段，确认保存，立即同步设置页。
5. 第一件心愿：可以输入“一双 Nike 699 块”，核对名称和预计价格，并必选高／中／低优先级。确认加入清单、冷静 3 天，不生成消费；可选设为许愿目标。已有目标默认不替换，须主动勾选。
6. 消费原则：一行一条，确认保存至执行页的购物原则；已有内容预填。
7. 准备完成：可选打开现有 CSV／XLSX 账单核对导入流程；关闭导入后接气泡教学。也可直接开始教学，或自行探索。

预算与心愿金额的“待填写（元）”为占位提示，点击后可直接输入数字和两位小数，也可全选替换或清空重填；提示文字不参与金额校验。已保存金额在返回、续接时预填，预算允许零额度，心愿仍要求有效的正金额。

气泡教学用遮罩与高亮定位实际控件，依次介绍主页、账单、清单、执行、复盘和设置。用户可以直接点击亮起的导航和手动记账按钮，进入真实页面；气泡按钮提供相同的键盘操作入口，Enter 前进，Esc 结束。教学本身不提交记账、商品分析或 AI 请求。支持上一步和结束导览；结束恢复原页面与记账输入模式。

每一步的“先跳过这一步”仅前进，保留原设置；顶部“稍后再说”结束整段引导。程序中途退出时记住已到达的设置步骤，下次从该步继续，未确认的表单草稿不落盘。已保存的心愿记住编号，返回／重启后重试不重复新增、不重启未修改心愿的冷静期。设置或数据库失败时保留当前页与输入，给出错误；许愿目标保存失败时明确说明心愿已加入清单，允许重试。

当前流程使用 `onboarding/version=2` 和 `onboarding/dismissed` 记住结束状态；完成整个气泡教学时 `onboarding/completed=true`。旧的纯文字导览完成标记不会阻止用户首次看到新版设置流程；已有数据会预填并保留。删除偏好或换用新的数据位置后会再次出现。程序更新保留偏好时不重复显示。

设置 → 关于与使用说明 → 重看新手引导，可随时重新进入。演示模式不自动弹出，允许从此入口进入，设置与示例数据都留在演示临时目录。

`onboarding_tests` 覆盖本地模拟 AI 测试与加密保存、双预算与价格换算、心愿／原则写入、必选优先级、跳过保留、旧导览升级、开屏与减少动画、关闭续接、心愿去重和冷静期保留、数据库失败、导入衔接、真实高亮点击、重看、三主题大字号与零消费写入。自动测试只使用临时数据和本地模拟服务。
