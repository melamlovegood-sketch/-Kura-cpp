# 原版开屏动画

桌面版普通启动、临时数据演示启动共用同一段 2.8 秒开屏，来源为原网页 `Kura/src/components/SplashScreen.tsx` 与 `Kura/src/index.css`。

- 固定米色背景 `#F5F0E8`，使用原版松鼠／橡果矢量路径及随应用分发的 DM Serif Display、DM Sans 字体。
- 0.2 秒开始橡果下落与两次弹跳；0.75 秒松鼠前倾后回正。
- 1.05 秒 KURA 上浮淡入；1.4 秒标语、1.7 秒副标题、2 秒底部署名依次淡入。
- 2.5 秒开始整体淡出，2.8 秒移除遮罩并恢复原页面焦点。开屏期间调整窗口大小仍覆盖整个内容区。
- 三套主题的开屏均使用原版米色，淡出后显示用户保存的主题。

实现为 Qt 原生绘制，没有新增浏览器或 SVG 运行库依赖，不改变数据库与页面导航。`splash_tests` 验证遮罩期间不误点页面、结束后恢复操作、缩放、透明淡出及播放中关闭窗口；可用 `KURA_SPLASH_PREVIEW_DIR` 导出各阶段和三套主题的预览。
