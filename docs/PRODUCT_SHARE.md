# 商品分享卡片

从清单商品的“商品资料”进入商品详情，点击“编辑”，可填写选填的“想买理由”（最多500字）和“替代品／其他办法”（最多1000字），支持多行。替代品可以是已有物品、其他候选商品，也可以写借用、继续使用旧物或暂时不买。原有购买理由自动带入，与待决定清单的购买理由保持一致；只补充商品资料不会重置冷静期。

点击“分享商品卡片”，预览即将导出的图片。卡片固定显示商品名称与当前记录价格，可选择包含商品资料、想买理由、替代品、需求备注和一张已保存的截图。需求备注默认不勾选；截图可以在商品录入原图和详情原图之间选择。空内容不占位，文字按实际长度换行，图片完整显示，卡片高度随内容变化。未保存的编辑草稿需要先保存或取消。

点击“复制图片”后，在微信等聊天窗口中粘贴发送，也可以点击“保存图片…”另存为PNG。卡片在本机生成，基础流程无需联网或AI。应用不发送微信消息，不创建分享链接、审批请求或投票，不接收或保存朋友的反馈；由用户自行交流和决定。

导出仅取预览中选中的商品内容，不包含账单、预算、AI对话或其他商品资料。价格标注为用户记录价格。截图按用户选择原样缩放展示，发送前可在预览核对，或取消勾选图片。

两个新增字段保存在现有商品资料的 `fields_json` 中，随商品流转、重启及完整备份保留，不新增云端存储或数据库业务表。个人理由与替代品由用户填写，商家截图识别不改写这两个字段；用户主动向AI提问时会作为个人决策背景提供。

验证由 `product_share_tests` 覆盖理由衔接、冷静期保持、重启、备份恢复、手动填写边界、草稿保护、选择性导出、复制与PNG保存、长文字和800×600窗口下三种主题的预览。
