# 统一待购清单 · 2026-10-28

清单以商品为中心，不再划分“待购／蹲价”页签。默认只显示尚在考虑的商品；每件商品都可打开自己的价格记录、走势、目标价和商品链接。列表只显示名称、一条状态和价格：有价格记录时显示最近价格，否则显示预计价格。

## 冷静期与操作

- 冷静期内显示灰底钟表图标，只有购买操作禁用。仍可展开商品、编辑资料、记录价格及放弃购买。
- 到期后恢复普通图标，状态为“待决定”，不使用绿色催购提示，也不改变排序。
- 倒计时只在商品行显示一次。展开区保留已填写的理由、购买操作和价格记录入口；资料、编辑、许愿目标、放弃、删除位于商品自己的菜单。
- 购买先核对实际金额，默认带入最近记录的价格；确认成功才记账并安排复盘。新增价格不会生成消费或重启冷静期。

## 排序

默认按添加时间从新到旧，编号用于同一时间的稳定排序。“···”菜单提供从旧到新、手动顺序与“调整顺序”。调整面板支持拖动及上下移动，只有保存后生效；取消保留原顺序。手动顺序会保留，新商品追加在已有手动顺序后。切回时间排序不会删除已保存的手动顺序。排序模式作为本机偏好存入现有 `.ui.ini`，具体位置进入完整业务备份。

## 原数据与备份

新增 `wishlist_price_links` 和 `wishlist_order` 两张表，保留原商品、价格历史、目标价、链接与商品资料。旧价格条目优先按明确的商品资料关联匹配，其次采用唯一的同名同品类待购商品；有歧义时分别保留。原来没有冷静期的价格商品不强加新的冷静期。原已结束观察的商品保留为历史归档，不会变成新的购买或放弃决策，也不会改变月度复盘统计。

同名不同规格的待购商品可分别记录价格，不共用记录。购买或放弃后停止价格提醒；删除商品保留价格历史且不会再次自动导回清单。完整备份包含商品与价格的关联和手动位置，兼容此前没有这两张表的备份。恢复前仍会自动备份当前数据。

验证覆盖统一入口、冷静期边界、首次截图识别的同款确认、同名规格隔离、排序保存／取消／重启、新商品追加、旧价格合并、删除后不重现、完整及旧版备份恢复、归档对复盘的影响和三种主题的小窗口。界面预览由测试临时数据库生成，位于 `build/preview/unified-list/`。
