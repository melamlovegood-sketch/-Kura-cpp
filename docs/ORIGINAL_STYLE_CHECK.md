## 验证结果

- Windows / MSYS2 UCRT64 / Qt 6.10.1 下，在独立英文临时目录构建 Release 源码快照，避免 Qt moc 的中文路径问题。
- 最终完整回归 17/17 通过，用时 29.13 秒。覆盖外壳导航、主题持久化、紧凑布局、执行分步流程、月度复盘、账单操作、预算、清单、导入导出及数据库异常处理。
- 通过实际 QFontInfo 检查，正文和空预算文案使用 DM Sans，品牌使用 DM Serif Display；两款字体的 Qt 资源均存在。
- 几何检查：首页容器宽 640px，购买入口宽 592px。入口的内容高度为 46px，含 Qt 样式边框后的实际控件高度为 48px。
- 生成七页 × 三套主题 × 两个窗口尺寸的外壳截图，并检查首页、空状态、设置、账单、复盘和深色紧凑首页。补充截图来自既有业务测试。截图均使用虚构／临时数据。
- 将 PATH 限制为预览目录与 Windows 系统目录，使用预览目录的 Qt 插件运行独立界面／字体检查程序，退出码为 0。

## 本地预览

`build/aesthetic-preview/Demo.cmd` 使用临时演示数据启动。`KuraCpp.exe` 使用正常的本机数据路径。

`build/aesthetic-preview/screenshots/` 保存截图及 `typography.json`。预览目录包含运行依赖和字体 OFL 授权，不依赖系统安装这两款字体。
